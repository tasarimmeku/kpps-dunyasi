# Quiz & Harita Dünyası — Privacy Policy

This repository hosts the **public privacy policy** for the Android app **Quiz & Harita Dünyası** (`com.meku.kpssdunyasi`).

## Privacy policy (Play Store URL)

After enabling GitHub Pages on this repository, use this URL in Google Play Console:

**https://tasarimmeku.github.io/kpps-dunyasi/privacy-policy.html**

Direct file: [privacy-policy.html](./privacy-policy.html)

## Enable GitHub Pages

1. Open **Settings → Pages** on GitHub
2. **Build and deployment → Source:** Deploy from a branch
3. **Branch:** `main` · **Folder:** `/ (root)`
4. Save and wait 1–2 minutes
5. Verify the URL above opens in a browser (no 404)

## About the app

Quiz & Harita Dünyası is an **offline, unofficial** study app with a question bank and map activities (Geography, History, Citizenship). It is **not** affiliated with ÖSYM or official KPSS examinations.
